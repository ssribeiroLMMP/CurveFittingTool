# Curve Fitting Application

Repository scaffold for the object-oriented Python/Tkinter curve-fitting application.

## Architectural reference

The normative baseline is located at:

`docs/Curve_Fitting_Application_Architecture_Baseline_v1.4.pdf`

Codex development instructions are defined in `AGENTS.md`.

## Repository layout

- `src/curvefit/` — production packages.
- `tests/unit/` — unit tests mirroring production packages.
- `tests/integration/` — cross-module and workflow tests.
- `tests/fixtures/` — curated, synthetic, non-sensitive test data only.
- `docs/` — normative project documentation.
- `examples/` — curated, non-sensitive example inputs.
- `scripts/` — future development/maintenance helper scripts.

No production code is included in this initial scaffold.
